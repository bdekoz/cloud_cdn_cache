产品优势

海量资源 全站加速

一站式加速

依托于遍布全球的优质节点，百度智能云CDN不仅可以加速小图片、apk、音视频等静态内容，也可以加速.asp、.php等动态内容，通过动静分离、智能路由、协议优化等多项技术一站式解决动静混合网站的数据传输问题，显著提升用户访问速度和体验。

智能调度 最优链路

用户在请求资源的过程中，可能受到运营商网络、客户端地域、源站带宽等因素影响，导致访问无法得到稳定快速的响应。百度智能云CDN自研的 GSLB 调度体系，实时智能地将用户调度至最优的边缘节点进行服务，保障用户能够快速稳定的获取资源。

  • IP库精准维护：IP库是调度系统判断用户所属地区与运营商，并以此来就近接入CDN节点的关键。百度智能云 CDN 对全球IP库数据进行高频更新，确保IP库实时校准。
  • 不同场景灵活调度：全方位支持DNS、HTTPDNS、302等多种解析引擎，灵活适配不同的业务场景需要。
  • 最优链路：全网节点状态实时监控，结合自研的GSLB调度体系和智能路由技术，为用户请求选择最优的网络链路，显著提升用户的访问体验。

功能丰富 一键接入

丰富的产品功能

百度智能云 CDN 产品提供了功能丰富的控制台和OpenAPI接口，可实现对内容加速业务的一站式配置和管理，主要产品能力如下：

  • 域名管理

    • 支持域名新增、删除、启用、停用。
    • 支持按照标签、源站、域名进行检索。

  • 域名配置

    • 支持自有源站和百度智能云对象存储源站，支持源站热备、权重回源。
    • 支持Referer黑白名单、IP 黑白名单、UA黑白名单、时间戳防盗链、IP 访问限频等丰富的访问控制策略。
    • 支持自定义资源缓存时间、忽略参数缓存、状态码缓存时间配置。
    • 支持range回源、回源301/302跟随、回源超市时间等配置。
    • 支持用量封顶、视频拖拽、HTTP响应头、页面压缩等高级配置。
    • 支持HTTPS加速、HTTP/2、HTTP/3加速。

  • 刷新预热

    • 支持自助进行全网缓存资源刷新，支持目录刷新与 URL 刷新。
    • 支持自助进行热点资源预热，降低用户访问延迟。

  • 统计分析

    • 支持1分钟粒度带宽、流量、流量命中率、请求数及状态码实时监控，支持域名、省份、运营商、协议筛选，全方位透视服务状态。
    • 支持1分钟粒度回源带宽、流量、请求数、状态码实时监控，支持域名、协议筛选，协助感知源站状态。
    • 支持不同时间周期数据对比，实时感知业务波动。
    • 支持对流量进行区域、运营商分布分析，支持URL、域名、IP、UA、referer不同维度的TOP信息展示。

  • 日志管理。

    • 支持自助下载所有访问请求产生的日志
    • 支持对访问日志实时采集与推送，用户可自助实现对日志的检索与分析。

灵活扩展

百度智能云 CDN 控制台上提供一站式配置能力，如基础配置无法满足您的业务个性化需求，可通过编程进行扩展。同时，基本产品能力均提供 API 接口，您可通过接口调用对 CDN 服务进行灵活操作。

  • 可编程自定义配置：部署配置简单，支持访问控制、重定向、限速等十几种场景自定义配置；支持EdgeJS 边缘服务功能，提供可编程的自定义边缘配置能力，您可在边缘节点执行自己编写的 JavaScript 代码。
  • 丰富的API接口：提供域名管理、域名配置、统计分析、缓存管理、访问控制、日志、工具等类型接口，详细操作可参见API参考。

一键接入

使用百度智能云 CDN 服务，无需您对现有业务内容进行任何改动或调整，接入流程简单快捷。

  • 一键开启：完成百度智能云账号注册与实名制认证后，您无需预先付费，即可一键开启 CDN 服务。
  • 平滑接入：您只需在 CDN 控制台中添加域名，系统会自动将域名配置推送至全网的加速节点，此时加速服务尚未生效，不会影响您的在线业务运行。
  • 轻松启动：当准备好启用加速服务时，只需在您的域名服务商处更新CNAME解析配置。当DNS变更生效，CDN加速服务便会即刻启动，为您的业务带来更快的访问速度和更佳的用户体验。

高性能缓存 强可靠防护

高性能缓存

百度智能云 CDN 采用自研高性能缓存系统，结合智能对象热度算法，分层多级缓存热点资源，有效提升缓存命中率，减少用户访问等待时间。

  • 高性能缓存：高性能的缓存Cache系统设计，超高速、大容量SSD存储，有效提升命中率，显著降低源站流量成本。
  • 智能对象热度算法：实时跟踪全局对象热度，多级、分层缓存热点资源，最大化利用缓存空间。
  • 分块存储：支持文件分块存储，文件淘汰时只需淘汰小数据块，杜绝大文件淘汰时回源流量突增风险。

强可靠防护

百度智能云 CDN 针对内容分发全流程提供可靠、立体化的防护保障，可帮助您规避潜在的业务安全风险。

  • DNS防劫持：采用HTTPDNS技术，将域名解析请求发送至百度智能云 HTTPDNS 服务端，可绕过运营商的Local DNS，从而避免由于Local DNS可能带来的域名劫持问题。
  • 传输加密：采用TLS（传输层安全协议）加密HTTP协议内容，支持TLS版本自定义以享受更强的加密能力与兼容性。即使数据在传输过程中被截获，攻击者也无法轻易解密并获取信息，可有效确保数据安全传输。
  • 身份认证：支持通过数字证书加密机制进行身份认证，支持双向认证，可有效防止假冒服务器的攻击。
  • 源站资源防盗：支持防盗链功能，客户可通过配置 Referer 和 IP 的黑白名单来保护源站资源。您还可以根据业务需要选择不同的鉴权方式对URL进行加密，实现对源站资源的保护。
  • 源站地址保护：启用 CDN 服务后，您的网站源站地址不会暴露在公网，可有效防范未经授权的访问及潜在的网络攻击。
  • 主备源站配置：支持配置主备源站，具备持续监控主备源站状态的能力，一旦检测到主站出现故障，将立即触发切换机制，并将服务请求重定向到备站，保证服务的稳定性。
  • 实时监控报警：CDN 监控系统可随时对您的服务进行监控，并及时提示报警，保障服务安全。
