Geographical Regions and Identifiers

Oracle Cloud Infrastructure is hosted in regions and availability domains. A region is a localized geographic area, and an availability domain is one or more data centers located within a region. A region is composed of one or more availability domains. For more information, see Regions and Availability Domains in Oracle Cloud Infrastructure Documentation. The following table lists the Oracle Fusion Cloud Enterprise Performance Management geographical regions.

Note:

The sender email ID for Cloud EPM communications for all environments is no.reply@epm.oraclecloud.com.
