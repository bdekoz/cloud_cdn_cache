服务域名

更新时间：2025-08-20

BCC API的服务域名为：

Region Endpoint Protocol Zone
北京 bcc.bj.baidubce.com HTTP and HTTPS cn-bj-b、cn-bj-d、cn-bj-e、cn-bj-f、cn-bj-h
保定 bcc.bd.baidubce.com HTTP and HTTPS cn-bd-b、cn-bd-c、cn-bd-d
广州 bcc.gz.baidubce.com HTTP and HTTPS cn-gz-c、cn-gz-d、cn-gz-f
苏州 bcc.su.baidubce.com HTTP and HTTPS cn-su-a、cn-su-d、cn-su-f、cn-su-h
香港 bcc.hkg.baidubce.com HTTP and HTTPS cn-hkg-a
武汉 bcc.fwh.baidubce.com HTTP and HTTPS cn-fwh-a
成都 bcc.cd.baidubce.com HTTP and HTTPS cn-cd-a
上海 bcc.fsh.baidubce.com HTTP and HTTPS cn-fsh-a

说明：BCC API支持HTTP和HTTPS两种调用方式。为了提升数据的安全性，建议通过HTTPS调用。
